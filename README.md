# Loracle — 리그오브레전드 패치 예측 모델

데이터: 2026.01 ~ / 패치 16.1 ~

Riot Games API로 수집한 랭크 게임 매치 데이터를 바탕으로, 다음 패치에서 챔피언이 버프·너프·유지될지 사전에 예측합니다.

---

## 프로젝트 개요

Riot Games는 약 2주마다 패치를 통해 챔피언 능력치를 조정합니다. 공식 발표 전까지는 어떤 챔피언이 변경될지 알 수 없지만, API를 통해 제공되는 매치 데이터로 승률·픽률·밴률 등의 통계 지표를 산출할 수 있습니다.

이 프로젝트는 그 통계 데이터로부터 다음 패치 방향을 예측하는 것이 가능한지 검증하고, 패치가 누적될수록 예측 정확도가 점진적으로 개선되는 모델을 구성하는 것을 목표로 합니다.

---

## 주요 기능

### 1. 데이터 수집
- 챌린저·그랜드마스터·마스터 랭커 목록 수집
- 랭커들의 최근 매치 ID 및 상세 데이터 수집
- 패치 스케줄에 따른 기간별 데이터 분리

### 2. 전처리
- 챔피언별 승률·픽률·밴률·OP지수·포지션 분산도 집계
- 포지션별 세분화 승률, 아이템 조합 승률 산출
- 전 패치 대비 델타(변화량) 계산

### 3. 패치 라벨링
- 공식 패치노트 크롤링으로 챔피언별 버프/너프/유지 라벨 자동 생성

### 4. 모델 학습
- **패치 단위 교차검증** 기반 역방향 제거법으로 최적 독립변수 선정 (24개 → 11개)
- LightGBM·XGBoost·RandomForest 성능 비교 및 최적 모델 선택
- SMOTE 과다추출로 클래스 불균형 처리
- OOT(Out-of-Time) 평가: 패치 1~N-1 학습 → 패치 N 예측
